# API da livraria

Veja o [README principal](../README.md) para executar e testar a API.

Comandos nesta pasta:

```powershell
npm.cmd ci
npm.cmd start
npm.cmd test
npm.cmd run client
npm.cmd run evidence
```

Execute start em um terminal e client em outro. Para evidence, a porta 5000 deve estar livre: o gerador inicia e encerra seu próprio servidor.
