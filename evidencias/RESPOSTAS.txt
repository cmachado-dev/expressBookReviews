PERGUNTA 1 - githubrepo

Comando (PowerShell):
curl.exe -fsSL --max-time 20 https://api.github.com/repos/cmachado-dev/expressBookReviews | ConvertFrom-Json | Select-Object full_name,fork,@{Name="parent";Expression={$_.parent.full_name}} | ConvertTo-Json

Saida real:
{
    "full_name":  "cmachado-dev/expressBookReviews",
    "fork":  true,
    "parent":  "ibm-developer-skills-network/expressBookReviews"
}

PERGUNTA 7 - register

Comando (execute na pasta final_project):
curl.exe -sS --max-time 20 -X POST http://127.0.0.1:5000/register -H "Content-Type: application/json" --data-binary "@scripts/payloads/register.json" --write-out "\nHTTP %{http_code}\n"

Saida real:
{
  "message": "Usuario cadastrado com sucesso."
}
HTTP 201

PERGUNTA 8 - login

Comando (execute na pasta final_project):
curl.exe -sS --max-time 20 -X POST http://127.0.0.1:5000/customer/login -H "Content-Type: application/json" --data-binary "@scripts/payloads/register.json" -c .evidence-session.cookies --write-out "\nHTTP %{http_code}\n"

Saida real:
{
  "message": "Login realizado com sucesso.",
  "username": "cristiano_demo"
}
HTTP 200

PERGUNTA 9 - reviewadded

Comando (execute na pasta final_project):
curl.exe -sS --max-time 20 -X PUT http://127.0.0.1:5000/customer/auth/review/1 -b .evidence-session.cookies -H "Content-Type: application/json" --data-binary "@scripts/payloads/review.json" --write-out "\nHTTP %{http_code}\n"

Saida real:
{
  "message": "Avaliacao adicionada com sucesso.",
  "isbn": "1",
  "reviews": {
    "cristiano_demo": "Excelente livro, com uma historia envolvente."
  }
}
HTTP 200
